description: Fixed format (also known as fixed-width) is a data interchange approach where every field has a predefined column width and is space-padded as needed. It contrasts with delimiter-separated formats like CSV, and is widely used in legacy mainframe systems, banking files, healthcare claims, government filings, and Unix system files such as /etc/passwd. While not an API in the REST sense, fixed-format files remain a critical data exchange medium that modern APIs and ETL pipelines must read and write.
